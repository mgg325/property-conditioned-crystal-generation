# Data

- `final_evaluations/` contains sample-level ledgers and source evaluation tables.
- `structures/` contains final generated and relaxed CIFs.
- `figure_data/` maps figures to the retained processed and final-evaluation tables.
- `verification/` contains metric checks from the released ledgers.
- `processed/` contains compact analysis inputs retained from the original workflows.

Raw training datasets, MP20, thermodynamic reference data, pretrained weights, and MatterSim/AnisoNet model assets are not redistributed.

Paths beginning `provenance://` are historical source labels, not file locations. Use the release-relative `generated_cif`, `relaxed_cif`, and `copied_relaxed_cif_path` fields to locate retained structures.
